# Internet_Plus_Plus
This is used in Sebs SW CV, But This is a stand alone version of it.
## Update on repository
Sadly this repository is no-longer in Development. Internet++ development has moved to a [new repository](https://github.com/SBFC-Group/Internetplusplus)

## Why?
Internet++ 4.0 was originaly two projects that had the same code. Project 1 was Internet++ for Sebs SW CV. Project 2 was Internet++ as a standalone program. 
But in mid-2025 i had stopped developing Sebs SW CV and had started a new project called [TryOS](https://github.com/sebastian2007bro/TryOS).
It needed a Web browser (used Internet++ 4.0 from Project 2) skip to April 2026 and the version of Internet++ at that time was getting old, and i wanted a new codebase for Internet++.
So i made Internet++ 5 an TryOS App. But i still wanted a standalone program version of Internet++, so i made a [TryOS AppEmulator](https://github.com/sebastian2007bro/TryOS-AppEmulator), that would allow me to run my TryOS Apps without having TryOS installed.

## Why an new repository
I wanted a new codebase, a new design and not thinking if old code would break it.
